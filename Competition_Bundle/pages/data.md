# Data
***
## 1. input_data in "Files" folder
Inside the input_data folder, you will find three files: X_train, y_train, and X_test.
You are expected to use the training data (X_train, y_train) to train your model. The X_test file will be used for evaluation.

You can check your score by uploading your solution to Codabench (Phase 1). In Phase 2, the final score will not be visible.

## 2. Data inside the Starting Kit
Inside the Starting Kit, data with the same structure as the full dataset is provided. You can use it to run and test the code included in the Starting Kit.

⚠️ **Important:** The data inside of the Starting Kit is not representative of the final dataset. The label distribution is different, and the dataset is significantly smaller.
