# Starting Kit
***
The Starting Kit is the place where you can dive into our challenge smoothly.

Start by downloading it here: [Starting Kit](https://www.codabench.org/datasets/download/f1a9311c-9320-4274-828d-c0e22fbf5c0b/)

## Overview
***
The Starting Kit contains:
* a README notebook to get you started
* the training data in "input_data"
* a sample model in "sample_code_submission"
* a sample model output in "sample_result_submission"
* the ingestion program in "ingestion_program" that automatically runs your model once submitted to Codabench

## README Notebook
***
You can simply start by reading the README notebook to begin working on your own submission for the competition. It consists of following sections:
* **The Challenge** - here you will learn there about the specifications of the data and the evaluation of this challenge
* **Setup instructions** - here you will see the requirements to create an environment to run your code
* **Data Loading** - here you will see how one can load the train and test data.
* **Training** - here we provide the code to train an example predictive model.
* **Visualisation** - here we provide you with visualisations of the train data and a confusion matrix for you to get a better understanding of how your model is performing
* **Scoring** - here you can see how your model will be evaluated and what scores we use
* **Submission preparation** - here we provide a code to zip your model, which you can directly use for submission to codabench.

After completing your model, simply run the README notebook. This will create a zip file of your model, which you can directly submit to codabench.
